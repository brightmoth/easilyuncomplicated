# Contributors

Thank you to everyone who helps make this project possible!

## How to contribute

1. Make your contribution to the project.
2. Open a pull request or contact the project maintainer.
3. Include the name you want credited, a short description of your contribution, the date, and any social links you’d like displayed.
4. The maintainer will add your details to the **Contributor credits** table below.

## How to edit this file

1. Open `CONTRIBUTORS.md` in the project repository.
2. Choose **Edit** (or open the file in a text editor).
3. Add a new row at the bottom of the **Contributor credits** table.
4. Replace the example details with yours. Keep the columns in this order: contributor, contribution, date, links.
5. Use this format:

   ```markdown
   | [GitHub username](https://github.com/username) | What you contributed | YYYY-MM-DD | [Social profile](https://example.com) |
## Contributor credits

When adding or updating contributor credits:

- Update the contributor credits page or file; do not add the credits to an unrelated page.
- Preserve the existing layout and formatting.
- Add one entry per contribution, using this exact format:

  | Contributor | Contribution | Date | Links |
  |---|---|---|---|
  | [GitHub username](https://github.com/username) | Brief description of the contribution | YYYY-MM-DD | [Social name](https://social-profile-url) |

- Use the contributor’s GitHub username as the displayed name and link it to their GitHub profile.
- Include only social links the contributor has chosen to share. If they provide none, write `—`.
- Describe the contribution clearly and briefly. Do not exaggerate or invent work.
- Use the contribution date supplied by the project or contributor. Format it as `YYYY-MM-DD`; do not guess a date.
- Do not invent or infer usernames, contribution details, dates, or social links. If required information is missing, leave it out and ask the maintainer.
- Ask for the contributor’s permission before publishing or changing their credit details.
- Keep entries in chronological order, oldest first. If two entries have the same date, keep their existing order.
- Check that Markdown links are correctly formatted and that the table remains valid after editing.
