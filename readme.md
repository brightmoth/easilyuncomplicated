# Easily Uncomplicated

**Simple on purpose.**

We make easy-to-use apps that do one job well. Your data and your privacy come first.

## About the project

Easily Uncomplicated is a collection of small, focused apps. The project is designed for static hosting, with no backend required for the planned apps.

### In progress

- **Timesheet:** A browser-based time and task tracker, planned to include overtime calculations, earnings summaries, CSV export, and local backup. See the [timesheet specification](timesheet/specs.md).

Features described in a specification may not be implemented yet.

## Privacy

- App data is intended to stay in your browser on your device. It is not sent to a project server.
- There are no accounts, logins, or ads.
- Because data stays on your device, apps cannot share it with each other or sync it across devices yet. Secure, optional syncing may be considered later.

## Contributing

Contributions and feedback are welcome. Before making a larger change, check the relevant app specification and open an issue or pull request so the scope can be discussed.

When opening a pull request, include a brief description of what you changed and any relevant testing or manual checks. Please do not include private data in examples or test files.

### Contributor credits

We want to recognize the people who help make the project possible. Contributors can ask to be included in the project credits when submitting a contribution or by contacting the maintainer.

Credits will describe the contribution briefly and include the date supplied by the contributor. We use a contributor's GitHub username and profile link; optional social links are included only when the contributor chooses to share them. We will ask permission before publishing or changing credit details, and will not guess missing names, dates, links, or contributions.

See the [contributor credit guidance](non%20code_syntax/how_to_give_credit.md) for the full process and format.
